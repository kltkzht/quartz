Definition

Chemische Energie → elektrische Energie
    
Reaktion läuft freiwillig (ΔG < 0)

zwei Halbzellen
    
verbunden durch:
    
    Draht (Elektronenfluss)
        
    Salzbrücke (Ladungsausgleich)
    Elektronenfluss

vom Reduktionsmittel zum Oxidationsmittel
    
von Anode → Kathode

Stromrichtung (technisch!)

entgegengesetzt zum Elektronenfluss
    
von Plus → Minus

Elektrodenreaktionen

Anode (Oxidation):  
Zn → Zn²⁺ + 2 e⁻

Kathode (Reduktion):  
Cu²⁺ + 2 e⁻ → Cu

Gesamtreaktion:  
Zn + Cu²⁺ → Zn²⁺ + Cu

E⁰

gemessen gegen Standard-Wasserstoffelektrode (SHE)
    
Einheit: Volt (V)
    

👉 Je positiver E⁰ → desto stärkeres Oxidationsmittel
