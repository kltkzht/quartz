Puffer bestehen aus schwacher Säure + ihrer konjugierten Base (z. B. CH₃COOH + CH₃COONa) oder schwacher Base + konjugierter Säure. Sie widerstehen pH-Änderung, indem hinzugefügte H⁺ von Base gebunden (A⁻ + H⁺ → HA) oder OH⁻ von Säure neutralisiert wird (HA + OH⁻ → A⁻ + H₂O) – Gleichgewichtslage bleibt stabil.
$$
pH = pK_s + \log_{10}\left(\frac{[A^-]}{[HA]}\right)
$$
Pufferwirkung ist begrenzt (bis eine Komponente verbraucht); abhängig von Konzentration (hohe [HA] und [A⁻] → höhere Kapazität) und Verhältnis (optimal bei 1:1). Bei Überschreitung bricht pH ein, wie in Titrierkurven sichtbar.
