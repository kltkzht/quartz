    ($\mathbb{R} \setminus {0}$)

**[[Mathe/Symmetrie]]**
- gerader Exponent:
    ( f(-x) = f(x) ) → **achsensymmetrisch** zur y-Achse
- ungerader Exponent:
    ( f(-x) = -f(x) ) → **punktsymmetrisch** zum Ursprung
    
**Grenzverhalten**
- ( n > 0 ):  
    $\lim_{x\to\pm\infty} x^n = \pm\infty$  
- ( n < 0 ):
    $\lim_{x\to\pm\infty} x^n = 0$
