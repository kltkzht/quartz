$$z = a + bi \quad (a,b \in \mathbb{R}) $$ 
- Realteil: Re(z) = a
- Imaginärteil: Im(z) = b

Addition / Subtraktion
$(a+bi)+(c+di) = (a+c)+(b+d)i$
Multiplikation
$(a+bi)(c+di) = (ac-bd)+(ad+bc)i$

## 5. Gaußsche Zahlenebene (Geometrie!)

Du solltest können:

- z als **Punkt (a,b)** interpretieren

- Argument = Winkel

## 6. Polarform (ETH-Klassiker)

### Definition

[  
z = r(\cos \varphi + i \sin \varphi)  
]

mit:

- ( r = |z| )
    
- ( \varphi = \arg(z) )
    

### Zusammenhang

[  
a = r\cos\varphi,\quad b = r\sin\varphi  
]

---

## 7. Euler-Formel (nur Verständnis!)

[  
e^{i\varphi} = \cos\varphi + i\sin\varphi  
]

👉 **Du musst sie nicht herleiten**, aber:

- wissen, **dass** sie aus **Taylorreihen** stammt
    
- wissen, **warum** sie nützlich ist

## 8. Potenzen & De-Moivre-Formel (sehr häufig!)

### De-Moivre

[  
(r(\cos\varphi+i\sin\varphi))^n  
= r^n(\cos(n\varphi)+i\sin(n\varphi))  
]

**Warum liebt ETH das?**

- Potenzen sind in Polarform **viel einfacher**
    
- Typische Kurzaufgabe:
    
    > „Berechne (z^{10})“
