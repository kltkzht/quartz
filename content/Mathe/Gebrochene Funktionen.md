$f(x)=\frac{p(x)}{q(x)}$ 
- (p(x), q(x)): Polynome
- **Definitionsbedingung:** (q(x)\neq 0)

- **Alle reellen Zahlen**, **außer** den Nullstellen des Nenners  
    D=\mathbb{R}\setminus{x\mid q(x)=0}    

- Zähler-Nullstellen **schränken den Definitionsbereich nicht ein**
- Nur der **Nenner** zählt

**Arten von Definitionslücken**

**1. Polstelle (echte Unstetigkeit)**
- Nenner = 0, Zähler ≠ 0
- Funktionswert → (\pm\infty)

**2. Hebbare Lücke**
- Zähler **und** Nenner haben gleichen Faktor
- Kürzbar → „Loch“ im Graphen

**Nullstellen**
 
f(x)=0 \iff p(x)=0 \quad \text{und} \quad q(x)\neq 0  
- Nullstellen kommen **nur aus dem Zähler**
- Nach Kürzen neu prüfen!


**Asymptoten**

**A. Senkrechte Asymptoten**
- bei **Polstellen**  
    $q(x)=0 ;\text{(nicht kürzbar)}$  

**B. Waagrechte Asymptoten**
Vergleich der **Grade** von Zähler ((n)) und Nenner ((m))

| Gradvergleich | Asymptote             |
| ------------- | --------------------- |
| (n<m)         | (y=0)                 |
| (n=m)         | $(y=\frac{a_n}{b_m})$ |
| (n>m)         | keine waagrechte      |

**C. Schräge Asymptoten**
- wenn (n=m+1)
- **Polynomdivision** durchführen  
    f(x)=\text{Gerade}+\frac{\text{Rest}}{q(x)}  

**C6. Grenzwerte**
- Bei (\pm\infty):  
    → Gradvergleich / Asymptote
- Bei Polstellen:  
    → links / rechts getrennt betrachten

**Symmetrie**
- **Achsensymmetrisch**:  
    f(-x)=f(x)    
- **Punktsymmetrisch**:  
    f(-x)=-f(x)  
    
**Ableitung (für Monotonie & Extrema)**
**Quotientenregel**
$\left(\frac{u}{v}\right)'=\frac{u'v-uv'}{v^2}$  
**Anwendung:**
- Monotonieintervalle
- Extremstellen
- Tangenten

**Skizzieren – empfohlene Reihenfolge**

1️⃣ Definitionsbereich  
2️⃣ Kürzen (hebbare Lücken!)  
3️⃣ Nullstellen  
4️⃣ Senkrechte Asymptoten  
5️⃣ Waagrechte / schräge Asymptoten  
6️⃣ Grenzverhalten  
7️⃣ (optional) Monotonie

**Definitionsbereich bestimmen**
Aufgabe:  
„Bestimmen Sie den Definitionsbereich der Funktion.“
Eigenschaften:  
Nenner ≠ 0
Grundidee:  
Nenner gleich 0 setzen → ausschließen

**Hebbare Lücke vs. Polstelle**
Aufgabe:  
„Untersuchen Sie die Art der Definitionslücke.“
Eigenschaften:  
Kürzen gemeinsamer Faktoren
Grundidee:  
Kürzbar → Loch, nicht kürzbar → Polstelle

**Nullstellen bestimmen**
Aufgabe:  
„Bestimmen Sie die Nullstellen der Funktion.“
Eigenschaften:  
Zähler = 0, Nenner ≠ 0
Grundidee:  
Nur Zähler relevant, nach Kürzen prüfen

**Senkrechte Asymptoten**
Aufgabe:  
„Bestimmen Sie die senkrechten Asymptoten.“
Eigenschaften:  
Polstellen
Grundidee:  
Nenner-Nullstellen, die nicht gekürzt werden

**Verhalten an Polstellen (links / rechts)**
Aufgabe:  
„Untersuchen Sie das Verhalten an der Polstelle.“
Eigenschaften:  
Vorzeichen von Zähler & Nenner
Grundidee:  
Grenzwerte links und rechts getrennt

**Waagrechte Asymptoten**
Aufgabe:  
„Bestimmen Sie die waagrechte Asymptote.“
Eigenschaften:  
Gradvergleich von Zähler und Nenner
Grundidee:  
Grade vergleichen, Leitkoeffizienten nehmen

**Schräge Asymptote**
Aufgabe:  
„Bestimmen Sie die schräge Asymptote.“
Eigenschaften:  
Grad(Zähler) = Grad(Nenner) + 1
Grundidee:  
Polynomdivision durchführen

**Grenzwerte im Unendlichen**
Aufgabe:  
„Bestimmen Sie (\lim_{x\to\pm\infty} f(x)).“
Eigenschaften:  
Dominanter Term
Grundidee:  
Asymptote oder Gradvergleich nutzen
