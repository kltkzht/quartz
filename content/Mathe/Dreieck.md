Schwerpunkt - 2/3 Seitehalbierenden
Yentrum des umreisender Kreis - senkrechte mitte

- Kreise → [[Mathe/Umkreis]] / [[Mathe/Inkreis]] eines Dreiecks
- Orthogonalität → rechtwinkliges Dreieck
- Flächen → Dreiecksflächen
- Vektoren → Dreiecke aus drei Punkten
- Raumgeometrie → Ebenenschnitte = Dreiecke

**Allgemeines Dreieck**
- Winkelsumme = 180

**Rechtwinkliges Dreieck**
- ein Winkel = (90^\circ)
- gegenüber liegt die Hypotenuse
- andere Seiten = Katheten
    
- [[Mathe/Pythagoras]]
$a^2 + b^2 = c^2$    
- [[Mathe/Skalarprodukt]] = 0
- [[Mathe/Thaleskreis]] = [[Mathe/Umkreis]]

**Gleichschenkliges Dreieck**
- zwei Seiten gleich lang
- gegenüberliegende Winkel gleich groß
- Symmetrieachse vorhanden
    
- Höhen, Winkelhalbierende und Mittelsenkrechten fallen zusammen aud Base
- Vereinfachung durch Symmetrieargumente

**Gleichseitiges Dreieck**
- alle Seiten gleich
- alle Winkel (60^\circ)
- alle besonderen Linien fallen zusammen

**Höhen**
- Senkrechte von einem Eckpunkt auf die gegenüberliegende Seite

- schneiden sich im Höhenschnittpunkt
- bei rechtwinkligem Dreieck: zwei Höhen = Katheten

- Flächenberechnung
- Orthogonalität erkennen

**Mittelsenkrechten**
- Senkrechte durch den Mittelpunkt einer Seite

- alle drei schneiden sich im [[Mathe/Umkreis]]mittelpunkt
- gleich weit von allen Eckpunkten entfernt

**Winkelhalbierende**
- halbieren einen Winkel

- schneiden sich im [[Mathe/Inkreis]]mittelpunkt
- Punkt ist gleich weit von allen Seiten entfernt

**Seitenhalbierende** (Medianen)
- verbinden Eckpunkt mit Mittelpunkt der Gegenseite
    
- schneiden sich im Schwerpunkt
- Schwerpunkt teilt jede Seitenhalbierende im Verhältnis 2 : 1
