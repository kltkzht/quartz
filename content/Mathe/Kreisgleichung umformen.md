(M → A):
1. Mittelpunktsform: (x - m₁)² + (y - m₂)² = r² aufschreiben
2. Klammern ausmultiplizieren:
   (x - m₁)² = x² - 2m₁x + m₁²
   (y - m₂)² = y² - 2m₂y + m₂²
3. Zusammenfassen:
   x² + y² + (-2m₁)x + (-2m₂)y + (m₁² + m₂² - r²) = 0
4. In Form x² + y² + ax + by + c = 0 bringen

Schritte (A → M):
5. x² + y² + ax + by + c = 0 sortieren
6. Quadratisch ergänzen:
   x² + ax → (x + a/2)² - (a/2)²
   y² + by → (y + b/2)² - (b/2)²
7. Einsetzen:
   (x + a/2)² - (a/2)² + (y + b/2)² - (b/2)² + c = 0
8. Konstanten auf andere Seite bringen
9. Mittelpunkt: M(-a/2, -b/2)
10. Radius: r = √[(a/2)² + (b/2)² - c] (wenn positiv)
