$\Delta U = Q + W$

- ( \Delta U ): Änderung der inneren Energie
- ( Q ): zugeführte Wärme
- ( W ): am System verrichtete [[Physik/Arbeit]]

- ( Q > 0 ): Wärme wird zugeführt
- ( W > 0 ): Arbeit wird am System verrichtet


**Isochorer Prozess**
- ( V = ) konstant
- ( W = 0 )  
    \Delta U = Q  

**Isothermer Prozess**
- ( T = ) konstant
- ( \Delta U = 0 ) (ideales Gas)  
    Q = -W 

**Adiabatischer Prozess**
- ( Q = 0 )  
    \Delta U = W
